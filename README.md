Amigo Secreto - Projeto ONE (Alura + Oracle Next Education)
Este projeto faz parte do programa Alura e Oracle Next Education (ONE), uma iniciativa que visa capacitar pessoas em tecnologia e conectá-las ao mercado de trabalho por meio de parcerias com empresas. O ONE é um programa de educação e empregabilidade com foco em inclusão e diversidade, promovendo o acesso à tecnologia para todos.

📝 Sobre o Projeto
O Amigo Secreto é uma aplicação simples desenvolvida em HTML, CSS e JavaScript que permite aos usuários organizar um sorteio de amigos secretos. Com uma interface intuitiva, o usuário pode adicionar nomes de amigos, visualizá-los em uma lista e realizar um sorteio aleatório para determinar quem é o amigo secreto.

Este projeto foi desenvolvido como parte do programa Iniciante em Programação G8 - ONE, que tem como objetivo introduzir conceitos básicos de desenvolvimento web utilizando as tecnologias mais populares: HTML, CSS e JavaScript.

📚 Sobre o Programa ONE
O Oracle Next Education (ONE) é um programa de educação e empregabilidade com objetivo social de capacitar pessoas em tecnologia e conectá-las com o mercado de trabalho por meio de empresas parceiras. O programa é uma parceria entre a Alura e a Oracle, e oferece formações em diversas áreas da tecnologia, desde iniciantes até níveis avançados.

Formação Iniciante em Programação G8 - ONE
Este projeto faz parte da formação Iniciante em Programação G8, que é voltada para pessoas que desejam dar os primeiros passos no mundo da programação. A formação aborda conceitos básicos de HTML, CSS e JavaScript, permitindo que os alunos criem seus primeiros projetos práticos.
